一、安装 Python
1. 打开 https://www.python.org/downloads/windows/
2. 下载 Python 3.12。
3. 安装时勾选 Add python.exe to PATH。

二、安装依赖
1. 解压本文件夹。
2. 在文件夹空白处按住 Shift 并点鼠标右键，选择“在终端中打开”。
3. 执行：
   py -m pip install -r requirements.txt

三、运行
1. 在紫鸟 LXN92:MAIN 中打开带知虾数据的 Shopee 搜索页。
2. 在终端执行：
   py collector.py
3. 输入 1 后，在 5 秒内点击紫鸟商品列表页面。
4. 每一页重复一次。
5. 输入 2 导出去重 CSV。

输出目录：
C:\Users\你的用户名\ShopeeCollector

注意：运行采集时不要操作键盘和鼠标。程序只复制当前页面地址和可见文字，不读取账号密码。
